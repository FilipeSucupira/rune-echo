# Imagens (opcional)

Coloque aqui os PNGs. Enquanto um arquivo não existir, o jogo usa **emoji** no lugar. Use fundo **transparente** (exceto as arenas) e pixel art de preferência.

| Arquivo | Tamanho | Uso |
|---|---|---|
| `monstro1.png` | 512×512 | Slime de Gelo (nível 1) |
| `monstro2.png` | 512×512 | Morcego Flamejante (nível 2) |
| `monstro3.png` | 512×512 | Golem de Musgo (nível 3) |
| `monstro4.png` … `monstro8.png` | 512×512 | níveis futuros |
| `mago.png` | 512×512 | mago do jogador |
| `arena_gelo.png`, `arena_fogo.png`, `arena_terra.png` | 1280×720 (sem transparência) | fundo da arena por tipo |
| `runa_F.png`, `runa_I.png`, `runa_T.png` | 128×128 | botões de runa (fogo, gelo, terra) |
| `equip_hint.png`, `equip_shield.png`, `equip_staff.png` | 128×128 | equipamentos (dica, escudo, cajado) |

Nomes exatos (minúsculas) são obrigatórios.
